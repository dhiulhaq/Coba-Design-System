Warna

Navy memimpin, amber hanya untuk satu fokus

Semua warna berasal dari logo. Navy untuk panel, tombol, dan teks penting. Amber hanya untuk angka besar (juz, tanggal) dan bintang.

Angka besar & badge tanggal

Angka besar solid amber, tidak outline, dan hanya satu per desain. Badge tanggal navy dengan label amber satu baris.

Ikon garis

Garis navy, dalam lingkaran biru muda. Set: kalender, pin, kitab, cari, daun, hewan, bintang, orang.

Ornamen

Semua turunan bintang di logo

"Binar" berarti cahaya. Tidak ada blob, gradien warna-warni, atau bentuk di belakang foto santri. Ornamen tidak boleh menimpa teks.

BintangSatu besar amber, 2–4 kecil putih atau amber.
Pola bintangGrid 64px, opacity ≤ 8%, dipudarkan di ruang kosong.
OrbitMaksimal 2 lingkaran putus-putus di sekitar bintang besar.
Emblem + sinarTeks seri melingkar, ikon kitab terbuka di tengah.
Tarbiyah
Watermark kataSora 600 sekitar 210px, putih 5–6%.
Foto memudarMask kurva ease (10 titik) ke navy, bukan gradien linear.

Claude Code

Terhubung ke Claude Code

Minta seperti biasa, misalnya "buatkan poster kajian Binar bulan depan". Claude Code otomatis memakai token, aturan, dan template di repo.

  1. Aturan baru yang disetujui dicatat di dokumen dan skill sekaligus.
  2. Perubahan dibuat di branch kerja, lalu di-merge lewat PR.
  3. Semua versi tersimpan di riwayat Git, jadi bisa dikembalikan.
