# Coba Design System

Repo ini berisi design system dan materi visual. Proyek utamanya adalah **Binar Sunnah School**.

## Design System Binar
Untuk pekerjaan apa pun yang berkaitan dengan Binar Sunnah School (poster, feed/story Instagram, banner, web, slide, dokumen visual), **wajib memakai skill `binar-design-system`** (`.claude/skills/binar-design-system/SKILL.md`). Pakai juga sumber berikut:

- Dokumen lengkap: `docs/binar-sunnah-school/Design System Binar.md`
- Token: `docs/binar-sunnah-school/tokens.css`
- Template resmi: `docs/binar-sunnah-school/templates/`
- Audit visual: `docs/binar-sunnah-school/brand-audit.html`

Dalam urusan warna, font, dan aturan, design system Binar mengalahkan skill desain umum (misalnya `banner-design`).

Aturan yang paling sering terlewat:
- Jangan pakai hitam/charcoal dengan amber. Untuk warna gelap, pakai navy.
- Logo Binar dan logo platform (YouTube, dll.) harus memakai file resmi.
- Foto santri tidak boleh di-commit.

## Kebiasaan repo
- Setiap keputusan desain baru yang disetujui user dicatat di `Design System Binar.md` **dan** di `SKILL.md`.
- Commit dan push ke branch kerja setelah perubahan selesai.
